---
title: "Interfaces that feel like objects"
description: "Why tactility is more about consequence than decoration."
publishedAt: 2026-05-07
draft: false
---

An interface feels tactile when actions have legible consequences. The button moves because it was pressed. The panel arrives from somewhere. The control remembers what just happened.

This is different from adding motion everywhere. Too much motion dissolves the relationship between cause and effect; everything moves, so nothing feels connected.

The objects I admire are quiet until they are used. Software can behave the same way.
